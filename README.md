# L'Intelligence Artificielle — Lycée Oukraf Mohamed

Site pédagogique d'une page sur l'intelligence artificielle, réalisé sous le label **ISZ** au **Lycée Oukraf Mohamed**.

## Ouvrir le site

Télécharger le dépôt, puis ouvrir `index.html` dans un navigateur. Aucune installation, aucun compte, aucune connexion : tout fonctionne hors ligne.

## Contenu

- **Cours** : définition, histoire, familles d'IA, applications, avantages, limites et éthique.
- **Encyclopédie** : 22 fiches filtrables par thème.
- **Quiz** : 8 questions avec correction et score.
- **Glossaire** : 18 termes techniques.
- **ISZ AI** : assistant local qui répond à partir d'une base de connaissances interne (mots-clés, similarité, tolérance aux fautes de frappe).
- **Recherche** interne (raccourci `/`), **thème clair/sombre** et **mode présentation**.

## Fichiers

| Fichier | Rôle |
| --- | --- |
| `index.html` | Structure et contenu de la page |
| `styles.css` | Palette ISZ (`#0B132B`, `#C0C5CE`, `#5BC0EB`), mise en page, responsive |
| `data.js` | Données : fiches, références, glossaire, quiz |
| `kb.js` | Base de connaissances et moteur de l'assistant ISZ AI |
| `app.js` | Affichage, recherche, quiz, chat, présentation, thème |

Aucune bibliothèque externe : uniquement du HTML, du CSS et du JavaScript natifs.
